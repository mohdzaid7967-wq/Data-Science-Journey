### 5. 📈 Linear Regression — Single Variable

Linear Regression is a supervised learning algorithm used to predict a continuous numerical value.

Topics practiced:

### 8. 🔤 One Hot Encoding

One Hot Encoding is a preprocessing technique used to convert categorical data into numerical values.

Example:

```text
Town
----
Delhi
Noida
Delhi
```

can be converted into separate numerical columns:

```text
Delhi   Noida
  1       0
  0       1
  1       0
```

Topics practiced:

- Categorical variables
- One Hot Encoding
- `OneHotEncoder`
- `ColumnTransformer`
- Data preprocessing

---

### 9. 🧩 PCA — Principal Component Analysis

PCA is a **dimensionality reduction technique** used to reduce the number of features while preserving important information.

Topics practiced:

- Dimensionality reduction
- Principal components
- Feature transformation
- Data visualization
- PCA implementation using Scikit-learn
