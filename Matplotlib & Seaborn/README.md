# Matplotlib & Seaborn — Data Visualization

This section of my Data Science Journey focuses on **data visualization using Matplotlib and Seaborn**.

The objective is to learn how numerical and categorical data can be transformed into meaningful visual representations and how visualizations can be used to identify patterns, distributions, relationships, and trends within datasets.
