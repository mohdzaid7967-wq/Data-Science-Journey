# NumPy — Numerical Computing with Python

This folder documents my hands-on journey with **NumPy**, one of the fundamental libraries in the Python Data Science ecosystem.

I have used Jupyter Notebook to explore NumPy from basic array manipulation to more advanced numerical operations.
